# Common Error Types Reference

## TypeError
- Undefined properties
- Null reference errors
- Type mismatches
- Incorrect function calls

## Network Errors
- ECONNREFUSED (connection refused)
- CORS (cross-origin resource sharing)
- Timeout errors
- SSL/TLS issues

## HTTP Errors
- 404 Not Found
- 500 Internal Server Error
- 401 Unauthorized
- 403 Forbidden

## Runtime Errors
- Memory leaks
- Stack overflow
- Resource exhaustion
- Deadlocks
